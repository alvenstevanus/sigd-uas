Backend API Web GIS — Kelompok 14

Kasus: Pemetaan PAUD, TK & Daycare di Pontianak Utara

Server Node.js dan Express berhasil berjalan dan melayani data GeoJSON.

Daftar Endpoint API:

  • GET /api/data/paud
    Menyajikan 32 data fasilitas PAUD, TK, dan Daycare dalam format GeoJSON.
  • GET /api/stats/jenjang
    Menyajikan statistik agregat jumlah fasilitas per jenjang dan akreditasi.
  • GET /api/data/zona
    Menyajikan data 2 poligon zona pendidikan anak dalam format GeoJSON.
  • POST /api/feature/zona
    Menyimpan poligon baru hasil digitasi ke file zona_pendidikan_anak.geojson.
